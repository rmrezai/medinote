# MediNote Pilot Success Metrics

## Safety
- Zero unresolved critical safety events attributable to MediNote.
- Zero confirmed cross-patient/cross-tenant disclosures.
- Adjudicate all consequential medication-state discrepancies.
- Diagnostic uncertainty must not be silently strengthened.

## Accuracy
Track physician-adjudicated factual accuracy, medication-state accuracy, certainty preservation, unsupported consequential claims, temporal errors, and disposition/discharge-action errors.

## Workflow
Track median generation-to-approval time, estimated baseline documentation time, physician edit ratio, generation failure rate, and module utilization.

## Alerts
Track critical/high flags, true/false positives, overrides and reasons, and resolution time.

No efficiency gain compensates for a material safety failure. Expansion thresholds require clinical/pilot leadership approval.
