# MediNote Physician Pilot Quickstart

1. Sign in and confirm the correct patient/encounter.
2. Import only through the approved pilot workflow.
3. Run Analyze; review current/historical state and contradictions.
4. Choose H&P, Progress, Discharge, Med Rec, or Signout.
5. Review every generated section; accept, edit, or regenerate.
6. Resolve consequential medication decisions explicitly in Med Rec.
7. Review Safety Flags; correct clinically meaningful discrepancies.
8. Approve/finalize only when output reflects your judgment.
9. Copy only final clinician-approved text into Epic.
10. Report safety/technical issues through the approved workflow.

MediNote is a drafting/reconciliation/audit assistant. The physician remains responsible for diagnoses, orders, medication decisions, disposition, and the signed record.
