# MediNote Pilot Physician Onboarding Checklist

- [ ] Named individual account created
- [ ] Correct organization and role verified
- [ ] Physician signs in successfully
- [ ] Physician understands MediNote does not autonomously diagnose/order/discharge
- [ ] Physician understands final documentation requires clinician review
- [ ] Synthetic chart import demonstrated
- [ ] Patient Overview reviewed
- [ ] H&P demonstrated
- [ ] Progress Note demonstrated
- [ ] Discharge demonstrated
- [ ] Med Rec confirmation demonstrated
- [ ] Signout demonstrated
- [ ] Accept/Edit/Regenerate workflow demonstrated
- [ ] Safety Review demonstrated
- [ ] Finalize/Copy-to-Epic demonstrated
- [ ] Physician knows how to report a safety issue
- [ ] Physician knows how to report a security/privacy incident
- [ ] Pilot scope and prohibited uses reviewed
