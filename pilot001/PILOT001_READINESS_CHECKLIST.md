# Pilot 001 Readiness Checklist

## Release
- [ ] RC v0.1 archive checksum verified.
- [ ] Clinical behavior freeze confirmed.
- [ ] Test environment health/readiness passes.

## Data
- [ ] Synthetic/de-identified cases only.
- [ ] Case IDs assigned before participant session.
- [ ] No live EHR/PHI connection enabled.

## Accounts
- [ ] Participant accounts created.
- [ ] Correct roles assigned.
- [ ] Test organization isolation confirmed.

## Session materials
- [ ] Master protocol available.
- [ ] Facilitator guide available.
- [ ] Observer rubric available.
- [ ] Feedback form available.
- [ ] Issue capture template available.

## Safety
- [ ] Hard-stop criteria reviewed with facilitator.
- [ ] Issue escalation owner identified.
- [ ] Build/checksum recorded on every session form.

## Post-session
- [ ] Findings adjudicated.
- [ ] Critical/high defects triaged before next participant.
- [ ] Day-1/Day-7 review completed as applicable.
