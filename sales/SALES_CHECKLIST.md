# First Hospitalist Customer Checklist

Before outreach:
- Working demo
- De-identified demo case
- One-pager
- Pilot proposal
- Pricing
- Security/deployment summary
- Validation summary
- Pilot protocol
- Draft agreement reviewed by counsel

First meeting:
- Discover current documentation workflow and pain
- Quantify physicians, shifts, discharge volume, current tools
- Demo in ≤5 minutes
- Confirm decision-maker and security/compliance path
- Ask for controlled pilot, not enterprise rollout

Before signing:
- Agree success metrics
- Identify pilot physician champion
- Complete institutional/security/privacy review
- Define PHI/data flow
- Complete required agreements
- Define support/escalation contacts
- Establish start/end dates

Day 30:
- Present measured results
- Ask: continue, expand with conditions, hold, or stop
- Convert only when the measured value supports it
