# MediNote 5-Minute Demo Script

## 0:00–0:30 — Problem
“Hospitalists do not just write notes. We reconstruct the same patient's state repeatedly across labs, medications, consultants, pending studies, therapy, and disposition. MediNote is designed around that inpatient longitudinal workflow.”

## 0:30–1:15 — Analyze
Open an encounter, import the approved source material, and click Analyze.
Show Patient Overview: current clinical picture, ranked problems, trends, medication states, pending items, consultants, disposition, and contradictions.

## 1:15–2:00 — Progress
Generate a Progress Note. Show evidence-linked problem sections and Accept / Edit / Regenerate.
Emphasize that the document consumes structured MCIF state rather than independently reinterpreting raw chart text.

## 2:00–2:45 — Medication reconciliation
Open Med Rec.
Show Home → Hospital → Discharge state and physician confirmation of a consequential medication transition.

## 2:45–3:30 — Discharge
Generate Discharge. Show diagnosis-organized hospital course, final medication transitions, pending items, follow-up ownership, and disposition.

## 3:30–4:15 — Safety
Show a deliberate discrepancy, such as note text saying “continue losartan” while the structured hospital state is held.
Run Safety Review and show the flag.
Explain that high/critical unresolved issues can block finalization.

## 4:15–5:00 — Close
“The value proposition is not AI prose. It is one reconciled inpatient state supporting five hospitalist workflows, with physician control and an audit layer. We propose a controlled 30-day pilot to measure accuracy, time, editing burden, discrepancy detection, and adoption.”
